# Manga Translator (Node)

URL/HTML → ค้นหา `<img>` → Vision LLM หาข้อความ+แปลไทย → แก้ข้อความออนไลน์ → render รูปใหม่ → สลับรูปกลับเข้าหน้าเว็บ

```bash
npm install
cp .env.example .env     # ใส่ GEMINI_API_KEY (Google AI Studio) หรือตั้งค่าในปุ่ม ⚙️ ของเว็บ
npm start                # http://127.0.0.1:3000
```

1. วาง URL (หรือ HTML) แล้วกด "ค้นหารูป" — รูปเล็กกว่า 150px ถูกข้าม
2. "แปลรูปนี้" / "แปลทั้งหมด" — ส่งทั้งรูปในคำขอเดียว (ติ๊ก "หั่นรูปยาว" ใน ⚙️ ถ้าเป็น webtoon ที่ยาวมาก)
3. แก้ข้อความ ลาก/ย่อขยายกล่อง ปรับขนาดฟอนต์และสี (กดค้าง "ดูต้นฉบับ" เพื่อเทียบ)
4. "ใช้รูปนี้" / "ใช้ทั้งหมด" เพื่อ render PNG ขึ้นเซิร์ฟเวอร์
5. เปิด `/view/<id>` เพื่อดูหน้าเดิมที่สลับรูปแล้ว หรือ `/api/projects/<id>/replacements` เพื่อเอา map (รูปเดิม → รูปแปลแล้ว) ไปใช้กับ userscript

หมายเหตุ: เซิร์ฟเวอร์ bind เฉพาะ 127.0.0.1 เพราะมัน fetch URL ที่ผู้ใช้ให้มา — อย่าเปิด `HOST=0.0.0.0` โดยไม่มี auth

## ใช้คู่กับ Chrome extension (`extension/`)

เหมาะกับหน้าที่ต้องล็อกอิน / lazy-load / render ด้วย JS เพราะ extension อ่านรายการ `<img>` จากหน้าที่เปิดอยู่จริง

1. `npm start` แล้วไปที่ `chrome://extensions` → เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ `extension`
2. เปิดหน้ามังงะ → คลิกไอคอน → **① ส่งรูปในหน้านี้ไปแปล/แก้ไข** (รูปที่ server โหลดเองไม่ได้ เช่น ต้องใช้ cookie หรือเป็น `blob:` extension จะโหลดแล้วอัปโหลดให้)
3. หน้าแก้ไขเปิดในแท็บใหม่ → แปล → แก้ข้อความ → กด "ใช้ทั้งหมด"
4. กลับมาที่แท็บมังงะ (ห้ามเปลี่ยน URL) → **② สลับเป็นรูปที่แปลแล้ว** — รูปบนหน้าจริงถูกแทนที่ทันที, "คืนรูปเดิม" เพื่อย้อนกลับ

ข้อจำกัด: เว็บ HTTPS ที่ server ไม่ใช่ localhost จะโดน mixed-content บล็อกรูปที่สลับ (ใช้ server บน `127.0.0.1` หรือวางหลัง HTTPS)
